## 🚀 Run Locally

### Clone

```bash
git clone https://github.com/prashantpiyush1111/prashant-maurya.git
cd prashant-maurya
```

### Open Directly

Open `index.html` in a modern web browser.

### Or Use a Local Server

With Python:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
